# Muh. Rezky Syaputra — Portfolio

Personal portfolio of Muh. Rezky Syaputra, Backend Engineer (Go/Golang).

- **Live:** https://rezky.kalodev.tech
- **Stack:** Astro (static) + Three.js (lazy-loaded interactive planet) + vanilla CSS
- **Theme:** monochrome space — black & white only

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/` and is deployed to Vercel.
